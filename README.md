# CODEX 灵宝（codex-lingbao）

给 [Codex++](https://github.com/BigPizzaV3/CodexPlusPlus) 做的一个**用户脚本**：AI 干完活，它用大白话告诉你「它动了啥、啥意思、对你有啥影响」。

> ⚠️ **非官方声明**：本仓库与 Codex++ 官方无关，是个人维护的社区脚本，按现状提供，不保证与所有 Codex++ 版本兼容。

## 它站在 CODEX++ 的什么位置

把 AI 编程想象成一层「双端翻译层」：

| 角色 | 谁在做 | 干什么 |
|---|---|---|
| 输入翻译 | 市场里已有脚本 *prompt-optimize* | 把你的糙需求翻成 AI 听得懂的精准指令 |
| **输出翻译** | **本脚本（CODEX 灵宝）** | **把 AI 干完的结果翻成你听得懂的大白话** |

一个管你别被 AI 误会，一个管你别被 AI 蒙住。本脚本填的是「输出翻译」那个目前没人做的洞。

## 功能

- **自动捕获**：监听对话区，AI 一回完话就抓到那段内容
- **完成检测 + 去重**：等文本稳定约 1.3 秒（生成结束）才播报，相同内容只播一次，不重复刷屏
- **人话播报（规则版，零依赖、免费）**：固定四块输出
  - ✅ 完成状态
  - 📦 改了什么（建/改了哪些文件、它自己跑了哪些命令）
  - 🧪 验证结果（跑通了 / 提到报错）
  - 👉 你要做什么（需要你运行的命令、要重启的服务）
- **命令四分类（可信核心）**：`已执行` / `建议用户执行` / `仅提及` / `无法判断`。**不把"让你运行"误报成"它跑了"**
- **风险提醒**：碰到密钥类内容、强力删除（`rm -rf`）等，单独标出；`.env.example` 等占位文件不误报
- **浮窗面板**：右下角小窗，历史上限 10 条，支持 **最小化 / 复制 / 关闭**
- **调试模式（默认关）**：开启后描出页面里像消息的节点，方便校准选择器；不开启时不会扫描全页、不打印回复内容、不改界面

## 安装

1. 把 `codex-lingbao.user.js` 复制到 Codex++ 的 `user_scripts` 目录：
   - macOS：`~/.config/Codex++/user_scripts/codex-lingbao.js`
   - Windows：`%APPDATA%\Codex++\user_scripts\codex-lingbao.js`
   - Linux：`~/.config/Codex++/user_scripts\codex-lingbao.js`
2. 在 `user_scripts.json` 的 `scripts` 里登记：
   ```json
   { "scripts": { "user:codex-lingbao.js": true } }
   ```
3. 完全退出并重启 Codex Desktop。

## 用法

让 AI 帮你干完一件事，右下角会自动弹出播报窗，读它就好——不用懂任何命令、不用翻英文。

## 文件结构

```
codex-lingbao.user.js        主脚本（安装它即可；翻译器由 build.js 内联）
announcer-translator.js      规则翻译器——单一可信源（被测试与发布版共用）
build.js                     把翻译器内联进主脚本，改翻译逻辑后必须跑
test-translator.js           node:test 真断言测试（node --test 运行）
CODEX灵宝-产品说明.md         面向非技术用户的普通话产品说明
```
